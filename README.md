# Руно

Лендинг вымышленного аукциона племенных овец. Структура взята у [21st.dev](https://21st.dev),
содержание переделано под овцеводство: живая панель торгов, ленты лотов с фильтром по породе,
ветпаспорт и родословная до третьего колена.

- `index.html` — сайт. Без сборки и зависимостей, шрифты с Google Fonts.
- `scene.html` — отдельная SVG-иллюстрация: аукцион барана на рыночной площади.

Названия хозяйств, клички и номера бирок вымышлены.

## Локально

```
python3 -m http.server 8000
```

Затем http://localhost:8000
